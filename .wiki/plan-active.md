# 현재 작업

규칙. `docs/roadmap.md`의 단계와 `docs/tasks.md`의 작업 큐를 읽고 다음 작업을 고른다.
첫 우선순위는 T1의 유효 제출과 T2의 dev 채점 기반이다. 명세·라벨·프롬프트는 파일럿부터 검증한다.
구현·live 실행·사람 승인을 확인하지 않고 해당 작업을 완료로 표시하지 않는다.

현재. T2는 구현·검증·로컬 머지 완료이며 사용자 지시로 별도 독립 리뷰를 생략했다.
프로젝트 공개 저장소는 `LittleBitAI/ai-nara-shop`이며 공개 기준 브랜치는 `main`이다.
이전 대용량 개발 이력은 로컬에 보존한다. 공개 main에 그 이력을 병합하지 않는다.
2026-09-16의 목표는 팀원 합류 전 T1 첫 제출이다. 두 노트북·공식 운영 규칙을 읽고
작은 결함 수정을 포함한 제출 ZIP의 로컬 검사를 마쳤다. 실제 실행 환경은 사용자가 선택한 대회 서버다.
2026-09-17 사용자가 로컬 T1 ZIP 제출 후 `청크 내 62번 공고: 정상 모델 응답 재시도 실패 (ValueError)`를 보고했다.
ZIP·코드 해시는 제출 전 기록과 일치한다. 서로 다른 5개 실패가 같은 문구로 표시되는 것을 재현했다.
실제 서버 응답·종료 사유가 없어 출력 잘림 등을 확정하지 않는다. 진단은 `reports/t1-baseline/server-failure.md`를 따른다.
후속 요청의 진단 JSONL·원인 traceback과 같은 제출 ZIP을 실행하는 Colab 노트북·번들 준비 및 로컬 검사는 완료했다.
검증 범위는 `reports/t1-baseline/diagnostics-colab.md`를 따른다. 독립 리뷰는 사용자 지시로 생략한다.
사용자 Colab A100 실행은 모델 다운로드 성공 후 ninja PATH 누락으로 초기화 실패했다.
공통 실행 환경과 사전 검사를 보완한 `1c64604`는 사용자 A100 40GB 실행에서 210건 실제 성공했다.
dev F1 0.2208013652894021, 순수 추론 371.6초. 서버 재제출은 미확인이다.
사용자가 서버 오류와 성능 둘 다 개선을 선택했다. 실패 공고 분할 재시도와
v10·v11·v13 제공 조문·품목 조회 파일럿을 구현한다. 새 후보의 GPU 실행·성능 개선은 별도 검증이다.
후속 `9363f21` Colab 실행은 210건 성공했지만 F1 0.18470988076251235로 하락했다.
사용자가 전체 프롬프트 법령 주입 철회·분할 복구 유지·3항목 별도 판정을 승인했다.
기본 24항목 프롬프트를 복원하고 동일 모델에서 3항목만 별도 호출해 병합한다.
Colab은 같은 실행의 기본/최종 CSV를 비교하고 점수 개선 전에는 제출 ZIP 자동 다운로드를 보류한다.
증거는 `reports/t1-baseline/colab-ninja-failure.md`를 따른다.

후속 clone 보완으로 Colab에서 공개 저장소의 실제 커밋을 기록하고 제출 ZIP을 자동 생성한다. 특정 로컬 ZIP 업로드도 선택할 수 있다.
사용자는 Colab 실행 노트북부터 준비를 선택했다. 다음은 `docs/colab.md`의 샘플 10건·dev 200건 실제 GPU 검증과 로그 분석이다.
