# feat: add shared agent setup entry point and pin tested wiki

무엇. Claude와 Codex의 팀 설치를 공용 `tool/setup_agents.py`에 모으고 프로젝트의
`tools/setup_agents.py`는 명시적 위키 위치와 자기 checkout만 전달하도록 했다.
설치된 호스트·기계별 hook은 Git에서 제외하고 프로젝트 슬롯은 로컬 adapter가 소유한다.

왜. 프로젝트 폴더명과 공용 위키 위치가 바뀌거나 같은 이름 checkout이 여럿이어도
설치가 서로의 설정을 덮지 않도록 하기 위해서다. 사용자 선택은 설치 도구까지 공용화였다.
고정 SHA의 임시 clone에서 설치·재설치·복구·공백/한글 경로를 검사했다.
