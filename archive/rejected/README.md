# 기각된 후보 보관

실측으로 기각된 후보를 둔다. **기본 읽기 대상이 아니고 운영 경로에서 부르지 않는다.**
`archive/contest/`와 같은 취급이다 — 근거 대조용으로만 남긴다.

지운 대신 남기는 이유는 하나다. **같은 것을 다시 제안하지 않기 위해서다.**
각 파일의 docstring이 실측 수치와 재현 명령을 들고 있다.
