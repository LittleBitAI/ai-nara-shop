## 규칙

- 같은 ZIP 재실행으로 그날 그 코드의 churn 을 잰다. 한 회차의 `dev` 와 `dev-debug` 로
  대신하지 않는다 — 이번 회차에서 그 둘이 0.006932 벌어졌다.
- **제출하지 않는다.** dev 0.70 전에는 점수 목적의 제출을 하지 않는다.
- 판정에는 대회 제공 자료만 쓴다. dev 정답은 발견과 사후 채점에만 쓰고 규칙의 조건으로
  쓰지 않는다.
- 회차 실행법은 `reports/team-c/merged-candidate/run-request.md`. `REPO_REF` 는
  **40자 전체 SHA** 여야 한다(약칭은 `fatal: couldn't find remote ref` 로 죽는다).
