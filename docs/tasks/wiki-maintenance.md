- 출력: 공개 버전 고정·두 호스트 연결, 내용 있는 공개 결정 기록, lint·설치 검사 결과.

## 공유 경계

공개 위키 저장소는 공통 규칙·도구를 제공한다. 프로젝트별 결정·진척도는 이 저장소의
`.wiki/decisions/`와 `docs/tasks/`, `reports/`에 남겨 프로젝트 저장소로 공개한다.
개인 대화 로그·trajectory·기계별 설정을 공개 위키에 복사하지 않는다.
팀원은 두 공개 저장소를 받아 프로젝트의 고정 SHA로 위키를 설치한다.
설치 검사와 직접 훅 실행은 자동 호스트 이벤트·신뢰 완료로 보고하지 않는다.
