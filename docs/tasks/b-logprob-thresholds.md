## 무엇을 바꿨나

- `script.py` — 기본 24항목 호출이 토큰 logprob 상위 5개를 받는다(`LOGPROBS_K`). `item_probabilities()` 가 항목마다
  `위반여부` 숫자 자리의 P(1) 을 읽어 응답 기록(`item_p1`)에 남기고, `apply_thresholds()` 가 파싱 직후 `ITEM_THRESHOLDS` 로
  위반여부를 정한다. 내린 항목은 근거를 비운다. 확률이 없는 옛 회차는 재생해도 그대로다.
- `tools/replay_run.py` — 저장된 `item_p1` 으로 같은 함수를 적용한다.
- `tools/tune_thresholds.py` — 격자 값마다 한 번 재생해 항목별 dev F1 최고 임계를 고른다. 동점이면 argmax 를 둔다.
