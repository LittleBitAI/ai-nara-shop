- `LLM(reasoning_parser="gemma4")` — vLLM 0.26.0 은 thought 채널이 끝난 뒤 JSON 스키마를 건다.
- 기본 호출의 첫 시도만 `enable_thinking=True`, `thinking_token_budget=512`, 출력 한도 +512, 프롬프트 예산 −512.
  추가 호출과 모든 재시도는 그대로 thinking 을 끈다.
- `extract_json` 이 표지 없는 thought 뒤의 마지막 JSON 객체를 읽도록 대비했다.
