## 목표와 가설

목표는 dev 200 밖에서 채택 판단을 할 정답을 만드는 것이다. 점수를 직접 올리는 작업이 아니다.
라벨러의 항목별 신뢰는 dev 200 보정으로만 정한다(확정 3). 신뢰 항목만 봉인 평가에 쓴다.

프롬프트·위키·보고서에서 모두 뺐다. 읽는 법은 [.wiki/law-reading.md](../../.wiki/law-reading.md).
