# labels-600 — 무라벨 600건에 외부 라벨을 붙여 dev 정답 셋을 늘린다

작업 ID / 제목: `labels-600` / 봉인 400 + 진단 200 라벨, 두 라벨러의 dev 200 보정
담당 역할 / 담당자: 구현자 / A+B(본인). [plan-0926-0929](plan-0926-0929.md)의 D 몫을 당겨 9/25 밤에 시작했다
상태: review — Luna 단독 보정·무라벨 600 라벨 완료(PR #151)

## 목표와 가설

목표는 dev 200 밖에서 채택 판단을 할 정답을 만드는 것이다. 점수를 직접 올리는 작업이 아니다.
라벨러의 항목별 신뢰는 dev 200 보정으로만 정한다(확정 3). 신뢰 항목만 봉인 평가에 쓴다.

## 라벨러

| | 명령 |

| Sonnet 5 | `claude -p --model claude-sonnet-5 --effort medium --tools "" --strict-mcp-config --system-prompt "..." --disable-slash-commands --no-session-persistence --output-format json` (본인 구독) |

두 라벨러 모두 `prompt.md` 를 고정 컨텍스트로, 공고만 새 입력으로 보낸다. Luna 는 developer 메시지에 명시적 캐시
중단점(`prompt_cache_breakpoint`, TTL 30분)을 걸고, Sonnet 은 `--system-prompt-file prompt.md` 와 `--stdin notice` 를 쓴다.
실측: Luna 둘째 호출부터 고정부 33,392토큰 캐시 읽기, Sonnet 52,185토큰 캐시 읽기.
번들은 저장소 밖에 만든다(정답 누출 방지).

웹 자료는 쓰지 않는다(2026-09-26 사용자 결정). 법령 지식은 제공 스냅샷에서만 오고, 세션 중 한 웹 검색의 내용은
프롬프트·위키·보고서에서 모두 뺐다. 읽는 법은 [.wiki/law-reading.md](../../.wiki/law-reading.md).
