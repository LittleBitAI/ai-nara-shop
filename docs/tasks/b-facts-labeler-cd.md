## 설계 — 라벨러는 원문을 옮기고, 적용 여부와 위반은 코드가 정한다

B 파일럿의 결론을 따른다. 범주 판단을 맡기면 읽기 오류가 나고, 원문 문자열을 옮기게 하면 코드가 가를 수 있다.
경쟁제품 여부·금액 구간·계약법처럼 운영 코드가 이미 정하는 적용 조건은 라벨러에게 묻지 않고 운영 함수를 그대로 쓴다.

| 키 | 라벨러가 옮기는 것 |
| --- | --- |
| `performance_texts` | 입찰참가자격으로 과거 실적(납품·수행·시공)을 요구하는 문구. 평가·배점표는 제외 |
| `institution_texts` | 입찰참가자격을 특정 기관·협회·회사의 회원·등록·협력업체로 제한하거나, 법령상 면허·등록을 넘어 특정 시설·지점망·인력 수 보유를 요구하는 문구 |
| `direct_production_texts` | 입찰참가자격으로 직접생산확인증명서 소지를 요구하는 문구 |
| `sme_texts` | 입찰참가자격을 기업 규모(중소기업자·소기업·소상공인·중기업)로 제한하는 문구. 제출서류 목록·제재 안내는 제외(S7-7·15) |
| `exception_texts` | 판로지원법상 소기업·소상공인 제한의 예외를 공고가 직접 적은 문구(S7-11) |
| `purchased_products` | 이 입찰로 사는 물품·용역의 이름, 원문 그대로 |

| 항목 | 코드 판정 (1 이 되는 조건) | 근거 |
| --- | --- | --- |
| v1 | 본문에 있는 `institution_texts` 가 하나라도 있음 | S7-5 — 법령 근거 없는 특정 시설·인력 보유 제한도 대상. 과업 관련성(S7-7·12)은 코드가 판단하지 않는다 |
| v2 | `performance_texts` 가 있고 추정가격 < 2억 3천만원, 단 지방계약법 + 수의계약 + 1억 미만은 0 | items.md v2 금액, S7-3 |
| 경쟁제품 | 운영 `competitive_product(rec, codes)` 가 True. codes = meta `세부품명번호목록` 의 10자리 + `purchased_products` 가 카탈로그 세부품명과 같은 것 | 운영 코드와 같은 카탈로그·상한 |

모든 문자열은 공백을 무시하고 공고 본문에 있을 때만 쓴다. 정보부족=true 인 공고는 판정 0 으로 두고 따로 센다.

## 고정한 것 — 결과를 본 뒤 바꾸지 않는다

- 신뢰 기준은 #127 과 같다 — 라벨러 F1 0.80 이상 신뢰, 0.60~0.80 조건부, 0.60 미만 제외. 모델 TP 셀 적중과 95% Wilson 하한을 함께 적는다.
- 결과를 본 뒤에는 형식 결함만 고친다. 의미를 바꾸면 dev 에 맞춘 판본이므로 `(낙관)` 을 붙이고 확정 신뢰로 쓰지 않는다.
- 제외된 항목은 오탐을 읽기 오류와 미작성 규칙으로 나눠 보고한다.

- v10·v11·v13: 라벨러가 아니라 코드의 경쟁제품 판정이 실패했다. 세 항목 정답 양성 공고 15 중 경쟁제품으로 잡힌 것이 2다.

  우리 모델 F1(0.35~0.42)이 낮은 이유도 같다. 이것을 풀지 않고 이 항목들의 정답을 늘릴 수 없다.

  구조 수리(문구와 함께 그 문구가 놓인 자리 — 참가자격 절·평가표·제출서류 목록 — 를 옮기게 하고 코드가 가른다)로 줄일 수 있는 꼴이다.

## v2 — v1·v2·v18 구조 수리 (사용자 결정, dev 를 본 뒤의 판본, 실행 전에 적음)

라벨러는 문구마다 원문 그대로의 `text` 와 그 문구가 속한 가장 가까운 절 제목 `heading`(원문 그대로, 없으면 null)을 옮긴다
(`question-cd-v2.md`). 자리 판정은 코드가 한다(`experiments/b13_cd_facts_v2_verdict.py`).

| 코드가 버리는 문구 | 조건 |
| --- | --- |
| 평가표 | `heading` 에 `평가`·`배점`·`심사`·`점수`, 또는 `text` 에 `N점` |
| 제출서류 목록 | `heading` 에 `제출서류`·`구비서류`·`첨부서류`·`증빙서류`, 또는 `text` 가 `N부` 로 끝남 |
| v1 에서만 | `text` 에 `소재지`·`영업소`(지역 제한 — v5~v7 의 영역) 또는 나라장터·`입찰참가자격 등록`(모든 입찰의 공통 요건) |

남은 문구로 v1·v2·v18 을 v1 과 같은 식으로 판정한다. 신뢰 기준도 같다. 이 판본은 오탐 목록을 본 뒤 만들었으므로
점수는 `(낙관)` 이고 확정 신뢰로 쓰지 않는다.
