## 운영진이 한 말

- S7-4: v9는 규격서 등에 특정 모델명·제조사명이 명시되면 성립한다. 규격·가격 동시입찰, 감점형 평가,
  응찰자 모델명 기입란은 배제 요건이 아니다.

  그 표현만으로 v9를 결정하지 말고 항목 정의와 문서 전체로 판단하라.

평가셋에는 "모델명 + 동등 이상" 으로 적힌 정답 1 공고가 있을 수 있고, 그 공고는 지금 전부 0으로 내려간다.

### H1 판정 단위 — 인용이 아니라 문서

S7-14 는 "항목표의 정의와 제공된 문서 전체를 기준으로" 판단하라고 한다. 모델이 고른 인용 하나에 모델명이
없다고 내리면, 다른 줄에 모델 지정이 있는 정탐을 지운다. 그래서 H1 은 이렇게 닫는다.

1. 모델이 v9=1 을 냈을 때, 인용이 아니라 그 공고의 `docs` 전부(`type` 이 `공고문` 인 것 포함)에서 모델 지정
   문장을 찾는다. 문서 종류로 좁히지 않는다 — 공고문에만 구매 모델을 적고 첨부에 반복하지 않는 공고가 있다.
2. 찾으면 v9=1 을 두고, 인용이 모델 지정 문장이 아니면 e9 를 찾은 문장으로 바꾼다. 바꾼 e9 는
   `clean_evidence()` 를 통과해야 한다(D4-4). 통과하지 못하면 모델 인용을 둔다.
3. `docs` 어디에도 모델 지정 문장이 없을 때만 내린다. 첨부가 입력에서 빠진 공고(레코드의 `dropped_doc_counts` 가
   비어 있지 않음, data.md D2)는 내리지 않는다 — 없는 것은 반증이 아니다.
4. 모델이 v9=0 을 낸 공고에는 손대지 않는다. H1 은 올리지 않는다.

알려진 비용: 문서 전체를 보면 A4 가 "공고문의 물품 내역표 한 줄" 이라 내린 `156`(`펙사론 | 농협케미컬 | …`)이
아래 표의 `브랜드 + 제품` 꼴로 다시 지정이 된다. 항목명이 "과업지시서" 인데도 S7-14 를 따르는 쪽을 택한 결과이고,
보고서에 이 셀을 따로 적는다.

모델 지정 문장은 코드보다 먼저 작업서의 표로 정한다. 구현 전에 이 표를 `reports/team-b/b6-v9-equivalent/` 에
채우고, 표에 없는 꼴을 코드에 넣지 않는다.
