# 대회 규칙

상태: 제공 규칙·데이터 명세·배포 README의 규정과 허용 범위를 통합한 작업용 계약입니다.
아래 내용만으로 규칙을 적용하며 원문 보관본은 필수 읽기가 아닙니다. 출처 ID는 [sources](sources.md)에서 추적합니다.
평가·운영은 [contest](contest.md), 입출력·실행은 [data](data.md)가 소유합니다. 최신 운영 공지는 별도 재확인 대상입니다.

## AI의 사용 절차

1. 작업 단계를 개발·라벨 생성 / 로컬 검증 / 제출 추론 / 패키징·제출 / 2차 평가 중에서 정합니다.
2. 아래 A표에서 이 작업에 활용할 수 있는 방법과 조건을 찾습니다. 명시적으로 허용된 방법을 막연한 우려로 금지하지 않습니다.
3. 해당 R규칙과 [데이터 계약](data.md)을 함께 적용합니다. 일반적인 허용이 모델 학습 금지 같은 개별 제한을 해제하지는 않습니다.
4. 불명확한 부분만 Q로 분리합니다. 그 답이 필요 없는 허용 작업은 계속합니다.
5. 작업서에 `단계 / 활용할 A-ID / 지킬 R-ID·조건 / 필요하면 Q-ID`를 기록합니다. 관련 없는 허용 방법까지 전부 구현할 필요는 없습니다.

대회에서 허용되는지, 성능상 채택할 가치가 있는지, 예산·실행 권한이 있는지는 각각 판단합니다.
허용된 기법은 실험 후보로 적극 검토하고 점수·근거 품질·총시간으로 채택합니다.
1회 호출·BM25 우선·작은 파일럿은 팀의 시작 전략이지 대회가 정한 상한이 아닙니다.

## 지역제한 금액과 고시금액

항목명의 `고시금액`은 항목마다 가리키는 금액이 다릅니다. 금액은 모두 추정가격(부가가치세 제외)과 비교합니다.
지방 시행규칙 제24조제2호 나목의 `행정안전부장관이 고시한 금액`은 법령패키지에 없고 S6이 제공합니다
(행정안전부고시 제2024-95호).

| 항목 | 국가계약 | 지방계약 |
| --- | --- | --- |
| v5·v6·v7 (지역제한) | 물품·용역 2억 3천만원 | 아래 지역제한 금액 |
| v2·v14·v15·v16 | 물품·용역 2억 3천만원 | 물품·용역 2억 3천만원 (지방 시행령 제20조제1항제3호·제5호, 판로지원법 시행령 제2조의2제1항제2호) |

지방계약의 지역제한 금액은 발주기관과 계약 종류로 정해집니다.

| 발주기관 · 계약 종류 | 지역제한 금액 | 출처 |
| --- | --- | --- |
| 시·도(세종특별자치시 제외)의 물품 제조·구매·일반용역 | 3억 5천만원 | S6 |
| 세종특별자치시·시·군·구의 물품·일반용역 | 5억원 | 시행규칙 제24조제2호 나목 |
| 교육청(학교 포함)·지방공기업의 물품·일반용역 | 5억원 | S6 |
| 건설기술·설계 및 공사감리·엔지니어링기술 용역 | 3억 3천만원 | 집행기준 제4장 제2절 |
| 안전점검·정밀안전진단 용역 | 1억 5천만원 | 집행기준 제4장 제2절 |

v5는 이 금액 이상인 계약의 지역제한입니다. v6·v7은 이 금액 미만이 전제이고, 지역 범위와 소액수의 특례 같은
나머지 조건은 [items](items.md)와 법령패키지를 따릅니다. 코드에서는 `script.py`의 `region_price_limit()`이 이 표를
적용합니다. 발주기관은 `공고문`에서 읽습니다 — 규격서·첨부의 기관과 납품 장소는 발주기관이 아닙니다.
발주기관은 익명화 토큰으로 가립니다([data](data.md) D3): 공고문의 첫 `[수요기관(…)]`이
`지방정부`·`광역자치단체`이면 시·도이고, `기초자치단체`이면 시·군·구입니다. 세종은 발주기관에 묶인 증거로만
가립니다 — 기관 토큰에 걸린 지역(`|지역=rN`), 기관 토큰 바로 뒤의 지역 토큰(`[수요기관(지방정부)] [지역:r1|…]`,
기관의 소재지), 평문이 세종의 부서를 발주처로 적은 것(`세종특별자치시 회계과`). 기관에 묶이지 않은 지역 토큰,
제한 지역, 참가 가능 지역 목록은 발주기관의 증거가 아닙니다. 지역제한은 현장·납품지가 있는 시·도로 걸기
때문입니다(지방 시행규칙 제25조제3항).
건설기술·설계감리·엔지니어링 용역과 안전점검·정밀안전진단 용역은 나라장터 `기술용역`이고, 데이터의
`업무구분`은 `일반용역`·`물품(내자)`뿐입니다. `일반용역`은 이 두 행에 해당하지 않는 것으로 읽습니다.
본문의 `실시설계`·`안전 점검` 같은 낱말로 두 행을 가리지 않습니다 — 제작·설치 용역의 부수 업무나
시설물안전법 밖의 점검까지 금액이 내려갑니다.

개인 법령 공부와 파이프라인에 법령 데이터를 결합하는 행위는 다릅니다.
개인 학습이 허용되어도 외부 법령 자료를 산출물에 반입할 수는 없습니다.
