# v1~v24 항목 색인

목적: AI와 팀원이 항목 번호의 뜻과 제공된 근거 조문을 바로 찾는 작업용 색인입니다.
원본: [항목표.json](../open/data/항목표.json), 원본 기준일 2026-07-27.
항목명·조문·비고는 원본 표기를 그대로 옮겼습니다. 띄어쓰기나 삭제 조항 표기도 임의 수정하지 않습니다.
원본이 바뀌면 이 색인도 대조·갱신합니다. 최종 판정은 제공 법령과 검토·승인된 상세 명세를 따릅니다.

## AI가 읽는 순서

1. 아래 표에서 `vN`의 공식 항목명과 부재탐지 여부를 확인합니다.
2. 항목 링크로 이동해 국가계약·지방계약 근거와 비고를 읽습니다.
3. [제공 법령 폴더](../open/data/법령패키지/법령/)에서 해당 원문을 확인합니다. 품목은 [중기부고시 폴더](../open/data/법령패키지/중기부고시/)의 제공 CSV를 확인합니다.
4. 조건·예외·정보 부족 처리는 [7칸 명세 계약](contracts.md#c3-7칸-명세-양식)에 따라 검토합니다.

`v1`~`v24`는 공식 데이터 키입니다. 향후 명세 파일명 `specs/v01.md`의 `v01`은 정렬용 표기이며 데이터 키를 바꾸지 않습니다.
이 색인은 항목의 정의와 원본 조문 안내까지 제공합니다. 상세 명세 파일과 `rules/law_map.json`은 아직 구현 전입니다.

## 읽을 때 주의할 구분

- `중기간`: 중소기업자간. `직생`: 직접생산 확인 관련 요건. `중소`: 중소기업. `SW`: 소프트웨어.
- v10·v11·v16·v18·v20은 부재탐지입니다. 위반 여부와 관계없이 대응 e열은 빈칸입니다. 입력 문서 누락과 실제 요건 부재를 구분합니다.
- v15는 소기업 제한, v16은 중소기업 제한 없음입니다. 금액 구간이 같아도 다른 항목입니다.
- v17은 중소기업 제한, v18은 소기업 제한 없음입니다. 두 항목을 합치지 않습니다.
- v22는 협상계약에만, v23은 협상계약이면서 지방계약인 경우에만 적용한다는 항목명 주석을 보존합니다.
- v24는 공고서와 나라장터 등록값의 불일치를 대조합니다. 연결할 법령 조문은 없으며 원본 비고는 예산·계약방법·지역제한·업종입니다.
- 항목명만으로 예외 없는 판정 규칙을 만들지 않습니다. 금액의 기준·경계, 예외, 조항 삭제의 의미는 제공 원문에서 확인합니다.
- 근거 조문은 검색·판정 참고 자료입니다. 제출 e열은 [데이터 계약](data.md#d4-모델-출력과-제출-출력)에 따라 공고 문서의 원문에서 인용합니다.
- 운영진이 토크에서 답한 항목별 판정 기준과, 운영진이 인정한 dev 라벨 노이즈는 [qna](qna.md)가 소유합니다.
  v1·v9·v10~v18·v24를 다루거나 dev 한 건의 라벨이 이상해 보이면 먼저 확인합니다.
