## 4. 검증과 한계

- 6개 로그 각각 `dev/submission.csv`와 현재 `open/dev_labels.csv`를 ID로 대응했다.
- 200개 ID 일치, 각 항목 TP/FP/FN, `2*TP/(2*TP+FP+FN)`, 24항목 평균을 재계산해 저장 지표와 일치 확인.
- `metrics.csv`의 담당별 범위는 B=v9·v19·v21·v24, C=v10~v18·v20, D=나머지 10항목이다. 누락·중복 없음.
- 본문 수치·관측성은 최신 CSV와 `open/dev.jsonl`에서 계산했다. 실행 가능한 기존 채점기는 `tools/score.py`를 사용한다.

```powershell
python -X utf8 tools/score.py --truth open/dev_labels.csv --pred <로그를 푼 경로>/dev/submission.csv --output-dir <새 채점 경로>
```

이번 진단은 실제 추가 모델 실행·법률 기준 확정·개선 효과 검증을 수행하지 않았다.
dev는 이미 반복 분석한 개발셋이며 독립 검증셋으로 부르지 않는다.
새 후보는 실제 모델 비교와 실행·시간 검사를 거쳐야 한다. 서버 성공은 별도로 확인해야 한다.
