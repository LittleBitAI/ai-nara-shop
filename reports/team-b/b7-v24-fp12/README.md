## 이 후보의 근거

조문이 아니라 dev 라벨이다. 운영진은 이 방향(메타 `지역제한여부=N` 인데 본문은 시·도 제한)을 묻자
답하지 않았고 "각 공고를 정의대로 비교하라" 고 했다(`docs/qna.md` v24 절, S7-14).
항목명 「공고서와 나라장터 입력값 상이」를 글자대로 읽으면 A 는 불일치다. 라벨은 12 중 11 을 0 으로 뒀다.
라벨러가 플래그 필드를 대조 대상으로 보지 않았는지, 나라장터에서 `N` 이 다른 뜻인지는 제공 자료로
가를 수 없다.

W5 가 경계하는 종류다 — dev 를 보고 만든 내리는 규칙이고, 9/21 A4 가 그런 규칙 묶음으로 서버에서 졌다.
다른 점은 둘이다. 라벨 쪽 근거가 모델 출력이 아니라 dev 200건 전체의 축별 비율이고(12 중 1),
무라벨에서 모델 양성 대비 몫이 dev 와 같다(0.93). 이것이 서버 이득을 보장하지는 않는다.
