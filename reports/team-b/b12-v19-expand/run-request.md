## Colab 에서

1. 노트북을 A100 런타임으로 연다. 보안 비밀 `HF_TOKEN` 접근을 허용한다.
2. 첫 코드 셀에서 `N_NOTICES = 6000` 을 `N_NOTICES = 10000` 으로 고친다. `REPO_REF` 는 그대로 둔다.
3. Drive `MyDrive/a5/unlabeled-d-14f03d1d5426/` 에 `u00`~`u11` 이 남아 있는지 본다. 있으면 건너뛰고 `u12` 부터 돈다.
   없으면 20묶음을 전부 다시 돌게 되므로(약 10시간) 돌리기 전에 알려 달라.
4. 런타임 → 모두 실행. 끊기면 처음부터 다시 모두 실행한다 — 끝난 묶음은 건너뛴다.
5. 끝나면 마지막 셀의 `unlabeled-d-results-*.zip` 을 받아 전달한다.
