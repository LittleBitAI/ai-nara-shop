## 7. 여기서 나오는 것 — 검증 안 된 가설 셋

**아래는 가설이고 아직 아무것도 안 쟀다.** 여기 적는 것은 다음에 무엇을 잴지
정하기 위해서다.

1. **`scope=competitive` 의 반증 문구.** `23` 은 "직접생산확인품목에서 **제외**하고
   일반물품으로 입찰공고합니다" 를 문서에 그대로 들고 있다. 이런 명시적 제외 문구가
   있으면 v10·v11 을 안 올린다 — 닿는 곳이 최대 2셀(`23` v10, 파생 없음).
   **금지선 확인 필요**: 정규식에 특정 공고 문구를 박는 것은 금지다. 제외 문구가
   **법령 조문 인용**(시행령 제7조제1항제4호)을 끼고 있다는 점이 다른 축일 수 있으나
   그것도 재생으로 먼저 재야 한다.
2. **제출서류 목록을 요건에서 빼기.** `13`·`075` 가 같은 유형이고 `qna.md` 가 원리를
   적는다. 닿는 곳 최대 2셀(v10 FN). 다만 이것은 **모델의 `direct_production_quote`
   해석을 바꾸는 일**이라 프롬프트·스키마를 건드리면 재생으로 못 재고 GPU 회차가
   필요하다. 후처리에서 인용문의 꼴(`가.`~`하.` 목록 항목)로 거르는 쪽이면 재생 가능.
3. **`069` 의 게이트.** 모델이 부재를 맞게 봤는데 `quoted(scope_quote)` 가 막았다.
   왜 막혔는지부터 봐야 한다 — 가설이 아니라 **확인할 사실**이다. 닿는 곳 1셀.

셋 다 **재생으로 먼저 잰다.** 상한이 1~2셀이라 GPU 를 태울 크기가 아니다.
