# A5 H3 — 지정 조건 관측을 기존 한 호출에서 먼저 남긴다

상태: 후보·파일럿 실행기 구현 및 CPU 계약 검사 완료. GPU 미측정, 미채택.
A5의 허용 범위인 experiments/·검사·노트북·보고서만 변경한다.
입력은 제공 dev 200건, 감사한 무라벨 5건, 기존 H4 dev-debug의 기본/SME 원응답이다.
출력은 대조군/후보 company_size 원응답·실제 문자 예산·시간·조건 인용 검사와
고정된 다른 단계 응답에 새 company_size를 결합한 CPU 재생 CSV/24항목 지표다.
규칙: A1·A4·A9·A10 활용, R1·R3~R5·R7~R10·R15·R19·R21 유지. 외부 API·법령 검색 없음.

## 시간부터 계산했다

회차 설계 전 기존 H4 측정에 다시 적용했다.
`1853/200*0.96=8.8944`, `7200-6380=820초`, `820/8.8944=92.192840초`다.
다른 단계가 동일하면 company_size 단계의 계획 상한은 `246.985+92.192840=339.177840초`다.
새 전건 호출 +1,637초는 총 8,017초라 기각한다. H3는 기존 호출을 교체하므로 호출 수 증가는 0이다.
출력이 늘어 실제 비용은 미측정이다. 계획 상한은 실측이나 서버 통과 보장이 아니다.
GPU 파일럿에서 실제 단계 시간을 잰 뒤 `6380+(새 단계초-246.985)*8.8944`로 환산한다.
H4 단계 시간과 비교하므로 토큰 준비를 포함한 stage_seconds를 쓰고 모델 적재는 제외한다.
초과하면 채택 후보가 아니며 전체 서버 검증을 진행하지 않는다.

## 한 가설과 보호할 경계

기존 company_size 한 호출에서 지정 코드·특이사항 원문 인용 최대 두 개·조건 상태를
scope보다 먼저 출력하면, 불투명한 범주+사업명 인용의 오류를 줄일 수 있는가를 묻는다.
고시 문구를 다시 하드코딩한 숫자 게이트나 공고 ID 예외는 만들지 않는다.
기존 H2의 observed_absence·후처리·다른 항목 소비자는 그대로 둔다.
새 필드는 근거 검사와 진단에만 사용하며, 이를 판정에 강제하는 효과를 이번에 섞지 않는다.
새 schema는 실험 프로세스 안에서만 활성화하고 종료/예외 시 복원한다. script.py는 변경하지 않는다.

두 인용으로 조건을 입증할 수 없으면 unobserved를 남긴다. 이 제한을 충족으로 둔갑시키지 않는다.
OR/AND·실제/최대 사양·기본/부스트 주파수·중량 정의·고도/반경을 구분하라고 지시한다.
숫자·모델명·공고 ID는 프롬프트에 넣지 않는다. 코드 없는 용역도 기존 서비스 후보에서 찾는다.
혼합 구매의 한 미확정 품목을 전체 구매의 비지정으로 확장하지 않는다.

## 파일럿의 순서와 해석

회차 1은 control → H3, 별도 새 런타임의 회차 2는 H3 → control 순서로 실행한다.
각 군에서 dev 200건과 이미 본 진단 5건을 따로 수집한다. 총 410응답/회차이며,
두 군은 비교 실험 비용이지 서버에서 둘 다 호출하는 구조가 아니다.
이전 H2 결과를 재개하지 않는다. 회차 번호별 새 출력 폴더를 사용하고 기존 폴더는 덮어쓰지 않는다.
진단 5건은 독립 평가·모집단 발화율·정밀도 표본이 아니다. 새 무라벨 일괄 수집은 없다.

각 군마다 고정 H4 기본/SME 응답에 새 company_size 응답을 결합하고 HEAD/H2 소비자로 재생한다.
이는 **company_size를 교체한 혼합 CPU 재생**이다. 전체 파이프라인의 새 GPU 점수라고 부르지 않는다.
24항목 변화·TP/FP/FN을 모두 기록한다. 각 군 내부 HEAD↔H2는 같은 사실의 후처리 효과이고,
control↔H3는 서로 다른 추론 결과이므로 churn과 분리되지 않는다. 별도 회차 반복을 함께 본다.

통과 조건: CPU 계약 검사·원응답 파싱/저장·인용 근거 검사·200건 재생이 먼저 성립해야 한다.
실제 회차에서는 조건 모순/미관측 보존, dev v11 회복과 다른 항목 손실, 동일 코드 반복 변화,
339.178초 계획 상한을 함께 본다. 002151 한 건 수정이나 Macro 증가만으로 채택하지 않는다.
시간 통과 후에도 전체 파이프라인 실제 GPU·서버 검증과 무라벨 검증은 별도로 남는다.

## CPU 검증

`python -X utf8 -m pytest tests/test_a5_scope_pilot.py tests/test_a5_collect_facts.py -q`
에서 5개 통과했다. 새 스키마 필수 필드 누락 거부, 인용 조작 탐지, 예외 시 원래 스키마/프롬프트 복원,
410건 경로의 CPU 모의 실행, 기존 결과 덮어쓰기 거부를 확인했다.
새 재생 경로에 기존 H4 company_size 원응답을 넣으면 보관된 HEAD/H2 CSV와 각각 바이트 동일하다.
초기 CSV 행 수 검사는 인용 안 줄바꿈을 행으로 잘못 세어 실패했고, 실제 CSV 파서로 고쳐 통과했다.
모의 응답의 지표·시간은 GPU 실측으로 기록하지 않는다.
로컬 GPU는 `nvidia-smi`로 RTX 3080 10,240MiB를 확인했다. 고정 모델의 실제 파일럿은 Colab A100에서 실행한다.
