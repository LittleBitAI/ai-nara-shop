## 4. 다음이 봐야 할 것 — 다섯의 원인 (정정됨)

> **이 절의 첫 판은 틀렸다.** 원래 "무변화 다섯은 원인이 하나로 모인다"고 적었다.
> 주 세션과 astra 가 같은 질문을 독립으로 분석해 **둘 다 그것을 반증했다.**
> 오답 공고 합집합 65건에서 쌍별 교집합이 0~3건뿐이라, 같은 몇 공고의 한 실패가
> 다섯 점수를 만든다는 설명은 성립하지 않는다.
> 주 세션의 판은 버렸고(PR #77 종료), **`reports/team-c/a5-label-definition/five-stuck-analysis.md`
> 와 `five-stuck-how.md`(astra)가 이 주제를 소유한다.** 아래는 그 요약이다.

무변화의 **직접** 원인은 하나다 — 이번 후보들이 이 다섯의 최종 판정을 바꾸지 않았다.
A4 가 바꾼 것은 v6·v9·v23, H2 는 v11 이고, 다섯 항목의 1,000셀이 기준과 모두 같다.
**그러나 낮은 F1 의 원인은 하나가 아니다.** 항목마다 막히는 층이 다르다.

| 항목 | 막히는 층 |
| --- | --- |
| v10 | 현재 소비하는 사실 조합으로 TP 와 FP 가 안 갈린다(12건 모두 같은 경로로 1). FN 3건은 각각 관측 게이트·제출서류 의미·적용대상 검증 |
| v13 | `baseline → SME → company` **경로 합성**. SME 가 0 으로 내린 것을 company 가 되살린 것 5건, 앞 단계 양성이 남은 것 4건 |
| v18 | 최초 차단이 범위 제외 3 + 범위 인용 1 + 자격 모순 1 + 완전관측 1 |
| v20 | FN 3건은 **실제 문서가 없다**(제안요청서 탈락·완전관측 false). `132` 는 `software_complete=true` 라 완전관측 실패가 아니다 |
| v24 | **`company_size` 소비 대상이 아니다.** 프롬프트를 바꿔도 나아질 경로가 없다 |

**살아남는 것은 원인이 아니라 비용이다.** 한 `company_size` 호출을 아홉 항목이 나눠 쓰므로,
그 프롬프트를 건드리면 아홉이 동시에 움직인다. h3 회차가 그 대가를 냈다 —
v18 +0.229 의 대가로 여섯이 무너져 Macro **−0.0497**
([회차 기록](../../runs/a5-scope-1789959906563639676/README.md)).
조건 관측은 200건 중 **128건이 `unobserved`** 다(met 42 · not_required 27 · contradicted 3).

astra 가 필드별로 갈라 보니 **h3 의 v18 이득은 `scope` 묶음에서, 손실은 다른 두 묶음에서**
각각 재현된다. 다음 한 수는 v18 적용범위다. 설계는 `five-stuck-how.md` 가,
착수 절차는 [`docs/tasks/a5-v18-scope-review.md`](../../../docs/tasks/a5-v18-scope-review.md) 가 소유한다.

**그 설계의 배선 전제는 주 세션이 CPU 로 미리 확인했다.** `verify_company_size()` 를
`scope` 만 바꿔 두 번 계산하고 `v18` 키 하나만 교체하면, v18 이 바뀐 공고 2건에
**v18 밖에서 바뀐 셀은 0건**이다. "v18 밖 23항목 차이 0셀"이라는 CPU 통과 조건은
배선 자체로 보장된다. 남는 위험은 **새 프롬프트가 legacy 필드를 흔드는 것**이고
`five-stuck-how.md` 가 그것을 CPU 로 증명할 수 없다고 이미 적어 두었다.

## 6. 이 정리가 증명하지 않는 것

- **`script.py` 는 아무도 안 고쳤다.** #69·#71·이 폴더 전부 0줄이다.
  머지는 후보를 `main` 에 올린 것이지 **채택이 아니다.**
- **서버에 한 번도 안 올라갔다.** 0.620382 는 dev 200건이고, 같은 코드의
  dev 0.599 대 서버 0.508 이 알려진 간격이다.
- **재생이라 회차 churn 이 없다.** 프롬프트가 바뀌면 다시 재야 한다.
- **A4 의 v23 규칙은 무라벨 배율 0.05 다.** dev 의 +0.214 가 비공개 집합에서 그대로
  나온다고 읽지 않는다. v6 1.11 · v9 1.16 은 건강하다.
- §2 의 "미완"은 **더 파면 된다**는 뜻이지 **된다**는 뜻이 아니다.
