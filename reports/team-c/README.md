### 3-2. 금액 게이트 — **조문에 없다**

- **제7조①** 에 금액 조건이 없다. 예외는 시행령 **제7조① 1~4호** 뿐이고,

- **제9조①** 의 "대통령령으로 정하는 금액 이상"은 **각 호(수의계약)에만** 걸린다.
  중소기업자간 경쟁 경로에는 금액 하한이 없다.

따라서 **v10·v11 에 금액 게이트를 넣지 않는다.** 적용 조건은 금액이 아니라 경쟁제품 해당 여부다.

### 3-3. 경쟁제품 조회의 판별력 — 하드 게이트로 쓰면 안 된다

`script.py` 의 `sme_product_lookup` 을 그대로 불러 dev 200건에 돌렸다
(`c4-v10-v11/probe_competitive_product.py`, 결과 `lookup-result.json`).

| 적용 게이트 | 항목 | 적용 건수 | 그중 양성 | **놓친 양성** |
| --- | --- | ---: | ---: | ---: |
| 코드일치(메타/문서) | v10 | 50 | 1 | **6** |
| 코드일치(메타/문서) | v11 | 50 | 3 | **3** |
| 코드 또는 품명 일치 | v10 | 65 | 1 | **6** |
| 코드 또는 품명 일치 | v11 | 65 | 3 | **3** |
| 게이트 없음 | v10 / v11 | 200 | 7 / 6 | 0 |

**경쟁제품 코드 일치를 적용 조건으로 강제하면 v10 양성 7건 중 6건이 사라진다.**
카탈로그는 **판정 재료로 프롬프트에 주고, 게이트로 쓰지 않는다.**

이유가 데이터에 있다. **v10·v11 양성 10개 공고 전부가 `업무구분=일반용역`이다.**
용역 공고는 `세부품명번호`를 물품 코드로 적지 않아 코드 일치가 성립하지 않는다.
그래서 `sme_product_lookup` 의 서비스 보조목록 경로가 켜진다 — 양성 10건 중 6건이
후보수 0 · 서비스보조목록 29행이고, 나머지 4건은 코드 일치가 있다.
**둘을 합치면 양성 10건을 모두 덮지만**(후보수>0 또는 서비스목록>0), 그 합집합은 200건 중 154건이라
게이트로서는 무의미하다. 이것이 "게이트 말고 재료" 결론의 근거다.

### 4-4. 200건 전수로 잰 신호

| 신호 | 적중 | 그중 양성 | 놓친 양성 |
| --- | ---: | ---: | ---: |
| `대기업 참여제한` 문구 | **0** | 0 | 5 |
| `상호출자` 문구 | **0** | 0 | 5 |
| 업종코드 `1468` 요구 | 7 | 4 | 1 |
| SW 언급 | 46 | 5 | 0 |

**결정적 사실: 대기업 참여제한·상호출자제한 문구가 200건 전부에 없다.**
제48조②·④가 요구하는 문구의 부재는 **보편적**이므로, 그 부재만으로는 5건을 가르지 못한다.
"부재 = 위반"을 그대로 적용하면 SW 사업 전건이 양성이 된다.

SW 언급 46건 안의 교차표:

| 갈래 | 음성 | 양성 |
| --- | ---: | ---: |
| 적용계약법 국가 / 지방 | 25 / 16 | **5 / 0** |
| 1468 요구 있음 / 없음 | 3 / 38 | **4 / 1** |
| 사업금액 <20억 / 20~40억 / 40~80억 / ≥80억 | 40 / 0 / 0 / 1 | 3 / 1 / 1 / 0 |

`적용계약법=국가계약법` **그리고** SW 사업자 자격을 요구하는 공고로 좁히면 양성 5건을 모두 덮고
오탐이 1건(`PPS-DEV-068`)이다. 하지만 **이것은 통계적 상관이지 조문이 아니다.**
제48조의 "국가기관등"에는 지방자치단체가 포함되므로, 지방 SW 공고 16건이 모두 음성인 것을
**조문으로는 설명할 수 없다.**

### 4-5. 결론 — **확정하지 못했다**

사용자 지시에 따라 명시한다. **v20 라벨의 구성 요인을 제공 조문으로 설명하지 못했다.**

- 대기업 참여 하한(제48조②·별표1)은 **단독으로는 아니다.** 하한 게이트는 양성 5건 중 3건을 버린다.
- 상호출자제한(제48조④)도 아니다. 그 문구는 200건 전부에 없다.
- 인용 오류설은 반증됐다.
- 남은 상관(국가계약법 + SW 자격 요구)은 조문 근거가 없다. **가설로만 적는다.**

**따라서 v20 에는 어떤 게이트도 넣지 않는다.** 근거 없는 규칙을 넣는 것보다 낫다.
