| v11 판정 방식 | TP | FP | FN | F1 |

## 무라벨 카나리 (W5)

규칙의 코드 쪽 조건은 잴 수 있다. `scope`는 모델이 쓰는 값이라 무라벨에 모델 출력이
없어 못 잰다.

| 조건 | dev 200 | 무라벨 6,000 | 배율 |
| --- | ---: | ---: | ---: |
| v12: 직생 요구가 있다 | 20.0% | 21.0% | 1.050 |
| v13: 직생 요구 + 카탈로그 경쟁제품 | 17.5% | 20.2% | 1.155 |

이 표가 증명하지 않는 것: 코드 쪽 조건이 두 집합에서 같은 비율로 있다는 것과
모델이 무라벨에서도 같은 비율로 `general`/`competitive`를 쓴다는 것은 다르다.
`competitive`가 dev에서 3.5% → 38%로 뛴 직후라 그쪽 확인이 특히 필요하다.

## 구조

`verify_company_size`가 두 축을 감싸는 껍데기가 됐다.

- `_company_size_bands` — 금액·등급 축. v14~v18. 반환 지점을 하나도 안 건드렸다.
- `company_size_products` — scope 축. v12·v13. 밴드 쪽이 `{}`(미확인으로 기본 판정 보존)를
  돌려줘도 독립적으로 선다.

노트북 `check_live`가 이 목록으로 보호할 열을 정하므로, 여기를 안 고치면 회차가
