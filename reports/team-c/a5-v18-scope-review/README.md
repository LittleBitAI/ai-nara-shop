## 실행과 기록

[run-request.md](run-request.md)의 고정 노트북으로 두 번 실행한다.
각 군 dev 200건, 총 400응답/회차. 별도 5건 진단과 무라벨은 이번 dev 전용 실험에서 생략했다.

각 회차는 원응답·실제 max_chars·공고별 프롬프트 해시·재시도/실패 로그,

control↔후보 OFF, control↔후보 ON, 후보 OFF↔ON, 같은 군 두 회차 비교를 생성한다.
