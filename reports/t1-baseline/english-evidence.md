## 목표와 이전 결과

사용자는 기존 품질 기준을 실제로 통과해 제출 ZIP 다운로드가 보류되지 않는 후보를 요청했다.
지시는 영어로, 법적 용어·항목명·제공 원문은 한국어로 유지한다. 영어가 더 정확하다는 가정은
이번 고정 모델·데이터에서 아직 실측하지 않았으며, 실제 점수로 검증한다.

직전 로그 `colab-results-1789613533157944500.zip`은 커밋 `57c78cf` 실행이다.
기본 F1 0.21114982591375778 → 최종 0.21100769349007198, FP/FN 합계 313 → 344.
v13 TP 3 → 4, FP 65 → 93이며 새 오탐 인용에 중기업·중소기업·중·소기업 허용 문구가 포함됐다.
v10 TP 0/FP 4, v11 TP 0/FP 0으로 부재 항목의 재현율 개선도 없었다.
dev 기본 추론 340.7초, 별도 단계 241.0초. 단순 지시 확장은 채택 근거를 만들지 못했다.

반면 PPS-DEV-121/125/175는 출력 2,048토큰·finish_reason=length로 JSON 파싱에 실패한 뒤
1항목씩 재시도해 모두 정상 응답으로 복구됐다. 실제 복구 증거이며 최초 서버 오류의 원인 증명은 아니다.
다른 21항목은 같은 실행의 기본 판정과 동일했다. 과거와 기본 예측의 변동 원인은 아직 미확인이다.

## 변경

- 기본 24항목, 별도 3항목, 재시도의 지시와 문서/누락 안내를 영어로 바꿨다.
  법적 용어·항목표 이름·제공 조문·공고 인용·제출 JSON 키는 한국어를 유지한다.
- 별도 판정에 facts 스키마를 추가했다. 품목 코드, 구매 대상 원문 인용, 적용 상태,
  실제 참가자격 원문 인용, 자격 범위/부재, 예외 상태를 판단 전에 추출하도록 한다.
  품목 코드는 10자리 또는 null, 인용은 160자 이하, 상태는 제한된 enum이다.
- 사실 필드 결손/타입 오류는 실패이며 기존 항목별 분할 복구로 처리한다. 복구 실패는 실행 실패다.
  정상 응답이 불충분한 사실을 담은 경우와 정상 응답 자체가 없는 경우를 구분한다.
- 판정 검증은 코드가 실제로 전달한 고시 후보에 포함되는지, 인용이 관측 문서의 원문인지,
  적용/예외/자격 상태가 위반 조건을 충족하는지 확인한다. 후보 목록은 제공 CSV에서만 만든다.
- v13의 중기업 포함 자격 인용을 차단한다. 법령 제목의 중소기업은 별도로 제외하여
  「중소기업기본법」 인용만으로 진짜 소기업 제한을 탈락시키지 않는다.
  검증한 참가자격 인용을 e13에 사용한다. 긴 복합 조항이나 인용 실패에서는 미탐이 늘 수 있다.
- v10/v11 부재는 완전관측·문서 무탈락·추가 절단 없음과 모델의 missing 판정이 함께 필요하다.
  불완전 입력의 실제 양성을 놓칠 수 있으나, 보이지 않는 자격을 없다고 단정하지 않는다.
- 같은 모델 인스턴스와 두 단계 구조를 유지한다. 기본 CSV와 최종 CSV의 다른 21항목은 동일하다.
  `sme_verified` 진단 및 검증 건수·탈락한 양성 수·문서 축소 수를 기록한다.

이 검증은 코드/인용/판정 상태의 일관성을 확인한다. 모델의 품목 대응·법령 해석이 전부 정확하다는
증명은 아니며, 새 후보의 실제 성능은 후속 Colab 실행으로 판단한다. dev 오답을 사용해 개발했으므로
dev는 독립 검증셋이 아니다. 정답·ID별 예외·다른 공고 정보는 추론 입력에 넣지 않는다.

## 비교와 다운로드

`baseline_submission.csv`는 영어 지시로 얻은 이번 24항목 첫 판정이다. 과거 한국어 메시지와의
동일성을 더는 주장하지 않는다. Colab 비교 기록에도 영어 첫 판정임을 명시했다.
실행 코드/언어/사실 검증 모드/검증 건수를 검사한 뒤 두 CSV를 채점한다.

다운로드 조건은 그대로다: 최종 F1 > 같은 실행 기본 F1, 최종 F1 ≥ 0.2208013652894021.
오류·품질 미달을 성공으로 표시하거나 품질 조건을 우회하지 않는다.
HF_TOKEN 다운로드, 서버와 같은 무인자 진입점·고정 모델/버전, ZIP 동일성 검사도 유지한다.
