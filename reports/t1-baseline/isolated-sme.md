## 새 실행 구조

1. 1c64604의 기본 메시지·스키마·설정으로 24항목 배치 추론을 먼저 끝낸다.
2. 같은 모델 인스턴스에서 v10·v11·v13만 법령·품목 자료와 별도 프롬프트/스키마로 배치 추론한다.
   이전 예측과 다른 공고 데이터는 전달하지 않는다. 제공 원문/조회 방법은 앞 파일럿과 같다.
3. 정확히 3개 키를 검증하고 해당 셀만 바꾼다. 나머지 21항목과 근거는 기본 판정을 유지한다.
   분할 복구는 기본 단계 6항목 단위, 별도 단계 1항목 단위이며 일부 실패를 0으로 메우지 않는다.
4. 둘 다 성공한 후 `baseline_submission.csv`, `submission.csv`, 실행 보고서를 남긴다.
   Colab은 두 CSV의 ID·비대상 셀 일치, 단계별 성공 수·시간, 각각의 F1·FP/FN을 확인한다.
5. 최종 F1 > 같은 실행 기본 F1이고 최종 F1 ≥ 0.2208013652894021일 때만 ZIP 자동 다운로드.
   실행 성공과 품질 통과는 각각 `colab_pass`, `quality_pass`로 구분한다.
