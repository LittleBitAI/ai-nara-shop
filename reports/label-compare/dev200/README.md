# 라벨러 dev 200건 보정 — 항목별로 무라벨 라벨을 믿을지 정한다

사람 검토 없이 무라벨 라벨을 쓰려면 라벨러의 항목별 오류율을 사람 정답(dev 200건)으로 먼저 잰다.
dev 가 사람이 만든 정답이므로 사람 확인을 이것으로 대신한다.

## 고정한 것

| 무엇 | 값 |
| --- | --- |
| 라벨러 | Opus 5.5 · effort medium, 도구 Read·Glob·Grep, 웹 차단 — 무라벨 D 회차와 같다 |
| 프롬프트 | `ba3f89c8…` (`tools/label_bundle.py export`, 선택 `all`, 200건) |
| 입력 | `open/dev.jsonl` SHA-256 `5507f5ab…` |
| 재사용 | `opus55-recall8`·`opus55-recall11` 19건 — 같은 라벨러·프롬프트, 공고 해시 19/19 일치. [seed19.jsonl](seed19.jsonl) |
| 새로 돌린 것 | 나머지 181건, 4묶음 병렬(`shard0~3.jsonl`) |

## 판정 규칙 — 결과를 보기 전에 정했다

항목마다 라벨러 `위반여부` 를 dev 정답과 비교해 TP·FP·FN 을 센다. `정보부족=true` 도 `위반여부` 값 그대로 센다.

| 라벨러 F1(dev 200) | 판정 | 무라벨에서 |
| --- | --- | --- |
| 0.80 이상 | 신뢰 | dev 측정에서 믿을 만한 라벨러. 무라벨 셀 확인에 쓸지는 방향별 조건(아래)이 따로 정한다 |
| 0.60 이상 0.80 미만 | 조건부 | 민감도·오탐률로 보정한 추정에만 쓴다 |
| 0.60 미만 | 제외 | 이 항목의 무라벨 라벨은 쓰지 않는다 |

항목당 양성이 5~8건이라 F1 한 칸이 약 0.08 움직인다. 문턱 근처 항목은 경계로 표시만 하고 규칙을 바꾸지 않는다.

판정은 dev 에서 잰 결과까지다. 신뢰 항목이라도 무라벨 라벨을 그대로 정답으로 쓰지 않는다(리뷰 라운드 1 에서 고침).
유병률이 dev 와 다르면 같은 민감도·오탐률에서도 양성 라벨의 정답률이 달라진다. 예: v2 는 민감도 0.86 · 오탐률 0.010 인데,
무라벨 발화율 0.17% 를 유병률로 놓으면 라벨러 `1` 의 정답률은 약 13% 다. 그래서 불일치 셀은 방향별로 따로 쓴다.

- 1→0(삭제) 셀: 라벨러 `0` 이 놓친 참양성을 민감도로 보정한다. 민감도는 dev 양성 전체가 아니라 모델 TP 셀의 적중이고,
  관측값이 아니라 95% Wilson 하한을 쓴다(결과표 `모델 TP 적중`·`Wilson 하한` 열, 리뷰 라운드 3 에서 고침)
- 0→1(추가) 셀: 라벨러로 확인하지 않는다. 라벨러 `1` 의 정답률은 그 집단의 참 유병률에 달렸는데, 무라벨이라 알 수 없고
  발화율은 참 유병률이 아니다(위 13% 도 발화율을 넣은 예시일 뿐이다). W5 대로 항목 정의와 대조해 확인한 n/k 를 적고,
  확인하지 못했으면 이 방향은 `미확인` 으로 남긴다(리뷰 라운드 2 에서 고침)

삭제 셀만 라벨러로 판정할 수 있는 것은 비대칭 때문이다. 손실률 상한은 삭제 대상과 같은 모집단(모델 TP 셀)의 민감도 하한만
필요하고, 라벨러 오탐은 손실을 부풀려 판정을 보수적으로만 만든다. 그 하한이 없거나 낮은 항목은 삭제 셀도 `미확인` 이다.

## 재현

번들은 저장소 밖에 만든다. 라벨 재생성은 모델 호출이라 결과가 바이트 동일하지 않다. 표는 아래 마지막 줄로 다시 낸다.

```bash
python -X utf8 tools/label_bundle.py export --bundle "$TEMP/label-dev200"
python -X utf8 tools/label_bundle.py run --bundle "$TEMP/label-dev200" --model opus55-medium \
  --out reports/label-compare/dev200/shard0.jsonl --ids <묶음 ID> \
  --cmd "claude -p --model claude-opus-5-5 --effort medium --allowedTools Read,Glob,Grep --disallowedTools WebSearch,WebFetch"
python -X utf8 experiments/labeler_dev200_calib.py
```
