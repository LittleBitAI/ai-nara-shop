# a5-scope 회차 — h3 프롬프트는 control보다 0.0497 낮다

2026-09-21 등록. 실행·판단은 A5 세션(astra)이 했고 이 문서는 주 세션의 등록·대조 기록이다.
전문은 이 폴더의 [`pilot/episode-1/run-record.md`](pilot/episode-1/run-record.md)가 소유한다.

**이 회차는 제출 파이프라인 회차가 아니다.** `company_size` 한 단계만 GPU로 돌리고
나머지는 보관 원응답으로 재생한 A/B이며 **제출 ZIP이 없다.**
아래 네 값을 [색인](../../../docs/runs.md#색인)의 전체 GPU 점수와 같은 저울로 읽지 않는다.

`head`는 기존 소비 경로, `h2`는 A5 H2 후보를 얹은 경로다. 순서는 control → h3.

한 호출의 사실을 여덟 항목이 나눠 쓰는 구조라 **프롬프트 한 번 바꾸면 여덟이 같이 움직인다.**

## 조건 관측이 실제로 얼마나 됐나

```
condition_states:  met 42 · unobserved 128 · not_required 27 · contradicted 3
competitive 인데 조건 근거가 없는 건: 88
```

**200건 중 128건이 `unobserved`다.** 조건을 분해해 물었지만 대부분 관측되지 않았고,
`contradicted`(조건과 어긋남)는 3건이다.

## 이 기록이 증명하지 않는 것
